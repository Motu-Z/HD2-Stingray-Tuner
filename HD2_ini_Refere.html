memory_size确定音频·缓冲按硬件
wwise.io_device.memory_size
出厂值26214400

Wwise 流式 IO 缓冲池字节数，对应 AkDeviceSettings::uIOMemorySize。块数 = 此值 / granularity，出厂 25MB/128KB = 200 块。影响音频预读能力，不直接改帧数。

wwise.io_device.max_concurrent_io
出厂值200

wwise.io_device.granularity
出厂值131072

Wwise 单次 IO 请求字节数，对应 uGranularity，出厂 128KB、SDK 默认 16KB。改它会破坏 memory_size / max_concurrent_io 的块数配套。

适用条件改动会破坏配套项

Wwise IO 调度模式，false 为 deferred。切 true 会退化为阻塞式调度并额外拉线程，增加 CPU 占用。

num_reserved_threads推定CPU·并行按硬件
win32.thread_pool.num_reserved_threads
出厂值2

线程池保留线程数。引擎作业线程数 = 逻辑处理器总数 − 此值，32 逻辑核时 2 对应 30 条、18 对应 14 条。影响 CPU 并行吞吐与 fork-join 尾延迟。已限制可用逻辑核集合时，按 reserved = 逻辑核总数 − 目标线程数 重新计算；限制方式包括 CPU Sets、BIOS 或处理器亲和性，与 CPU 厂商和核心拓扑无关。

适用条件已限制游戏可用逻辑核集合时才需要改
